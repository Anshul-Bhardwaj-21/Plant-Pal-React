📋 PROBLEM: Apple plant giving different results each time

🔍 ROOT CAUSE: Missing .env file with Gemini API key

✅ SOLUTION: Follow these 5 simple steps (takes 5 minutes)


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: Create .env File                                                    │
└──────────────────────────────────────────────────────────────────────────────┘

In your project root folder, create a new file named:  .env

Copy this template:

VITE_GEMINI_API_KEY=your_key_here
VITE_FIREBASE_API_KEY=your_key_here
VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your-project-id
VITE_FIREBASE_STORAGE_BUCKET=your-project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=123456789012
VITE_FIREBASE_APP_ID=1:123456789012:web:abc123
VITE_WEATHER_API_KEY=your_key_here


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: Get Gemini API Key (MOST IMPORTANT)                                 │
└──────────────────────────────────────────────────────────────────────────────┘

1. Go to: https://makersuite.google.com/app/apikey
2. Click "Create API key"
3. Copy the key (starts with AIza...)
4. Paste it in .env file:

   VITE_GEMINI_API_KEY=AIzaSy_YOUR_ACTUAL_KEY_HERE


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: Get Firebase Keys (Optional but Recommended)                        │
└──────────────────────────────────────────────────────────────────────────────┘

1. Go to: https://console.firebase.google.com/
2. Create new project or use existing
3. Click "Web" icon (</>) to register app
4. Copy all the config values to .env

See API_SETUP_GUIDE.md for detailed instructions.


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: Get Weather API Key (Optional)                                      │
└──────────────────────────────────────────────────────────────────────────────┘

1. Go to: https://openweathermap.org/api
2. Sign up for free account
3. Copy API key from dashboard
4. Add to .env:

   VITE_WEATHER_API_KEY=your_weather_key_here

Note: Wait 10-15 minutes after creating account for key to activate.


┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 5: Restart Development Server                                          │
└──────────────────────────────────────────────────────────────────────────────┘

IMPORTANT: You MUST restart the server after creating .env

1. Stop server: Press Ctrl+C
2. Start again: npm run dev


┌──────────────────────────────────────────────────────────────────────────────┐
│ VERIFY SETUP                                                                 │
└──────────────────────────────────────────────────────────────────────────────┘

1. Open: http://localhost:5173/diagnostics
2. Click "Run Diagnostics"
3. All checks should show ✅ OK

If you see ❌ FAIL:
- Check .env file exists
- Verify API keys are correct
- Ensure no extra spaces or quotes
- Restart server again


┌──────────────────────────────────────────────────────────────────────────────┐
│ TEST PLANT IDENTIFICATION                                                    │
└──────────────────────────────────────────────────────────────────────────────┘

1. Go to: http://localhost:5173/add-plant
2. Click "Scan Plant" tab
3. Upload your apple plant image
4. Note the result
5. Upload THE SAME image again
6. Result should be IDENTICAL

✅ EXPECTED: Same plant name, same confidence score
❌ PROBLEM: Different results = API key not working


┌──────────────────────────────────────────────────────────────────────────────┐
│ WHAT EACH API KEY DOES                                                       │
└──────────────────────────────────────────────────────────────────────────────┘

🤖 GEMINI_API_KEY (CRITICAL for your issue)
   - Plant identification
   - Disease detection
   - AI chatbot
   - Age estimation
   → Without this: Inconsistent results!

🔥 FIREBASE_* (Recommended)
   - Save plants to database
   - Store plant images
   - User authentication
   → Without this: Data not saved

🌤️ WEATHER_API_KEY (Optional)
   - Weather widget
   - Smart watering advice
   - Weather-based care tips
   → Without this: No weather features


┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

❌ "Cannot find .env file"
   → Create .env in project ROOT folder (same level as package.json)

❌ "API key not valid"
   → Check key starts with AIza
   → Remove any quotes or spaces
   → Wait a few minutes and try again

❌ "Still getting different results"
   → Open browser console (F12)
   → Look for error messages
   → Check if Gemini API is being called
   → Run diagnostics at /diagnostics

❌ "Diagnostics shows FAIL"
   → Read the error message
   → Follow the suggested fix
   → Restart server
   → Run diagnostics again
